## 💻 स्थानीय स्तर पर कैसे चलाएं (How to Run Locally)

किसी जटिल बिल्ड टूल या पैकेज मैनेजर की आवश्यकता नहीं है:

### विकल्प 1: सीधे ब्राउज़र में खोलें (Direct Browser)
- `index.html` फ़ाइल पर राइट-क्लिक करें और अपने पसंदीदा ब्राउज़र (Chrome, Safari, Firefox, Edge) में खोलें (Open With)।

### विकल्प 2: Python लोकल सर्वर (अनुशंसित)
यदि आपके कंप्यूटर पर Python स्थापित है, तो टर्मिनल में इस डायरेक्टरी में जाएं और टाइप करें:
```bash
# Python 3
python3 -m http.server 8000
```
इसके बाद ब्राउज़र में `http://localhost:8000` खोलें।

### विकल्प 3: VS Code Live Server
यदि आप VS Code का उपयोग करते हैं, तो `Live Server` एक्सटेंशन के माध्यम से `Go Live` पर क्लिक करके भी इसे देख सकते हैं।
